Local Theft Auto lives inside Ollama Chat.

Ollama Chat is a small local web UI for chatting with models served by Ollama — a thin Express proxy plus a clean conversational frontend, with nothing you type or generate leaving your machine. Local Theft Auto is a standalone bonus canvas game that happens to ship in the same codebase, using the little chat widget in the corner of this site as its one link back.

01

what’s inside ollama chat

A local assistant, fully stacked.

Streaming chat

Replies arrive token by token as Ollama produces them. Stop mid-stream any time — the server aborts upstream the moment you disconnect.

Model management

Pull new models with live progress in the UI, switch your default, delete what you don't use — all from the Settings modal.

Semantic memory

Ollama embeds, Qdrant indexes, everything stays local. Off until you call it.

Chat compaction

Long conversations get older turns summarized so they fit the context window; recent messages stay verbatim.

Attachments

Clip .md, .csv, .py and other text files onto a message — read in your browser, no upload route exists.

Accounts that stay local

Scrypt-hashed passwords, HttpOnly session cookies, SQLite via Node's built-in driver. Your sessions are scoped to you alone.

Three ways in

A browser tab (npm start), a native Electron desktop app, and a Flutter mobile client for iOS/Android over your LAN.

Private by architecture, not by policy.

  • Your words travel to 127.0.0.1 and back — the proxy's only upstream is your local Ollama.
  • Passwords hashed with scrypt; sessions ride HttpOnly, SameSite cookies valid for 30 days.
  • Chats and memory are scoped per user, stored in a git-ignored ./data folder.
  • Logs carry method, route, status, duration. Never message bodies.

The honest footnote: Ollama Chat is built for a trusted machine or local network, not the open internet — that's stated plainly in the README, not implied by silence.

02

from zero to chatting

Four steps. All of them local.

  1. Start Ollama

    Install Ollama if you haven't, then run it — or just keep the Ollama desktop app open in the background.

    ollama serve

  2. Pull a model

    Any model Ollama serves will do. You can also pull and delete models later from the app's Settings modal.

    ollama pull llama3

  3. Run Ollama Chat

    One command installs and starts the server — a thin proxy on port 4173 in front of Ollama on 11434.

    $ npm install && npm start

  4. Open and sign up

    Create your local account once — then every session, chat and memory index is scoped to you on this machine. Requires Node.js ≥ 22.5.

    http://localhost:4173
