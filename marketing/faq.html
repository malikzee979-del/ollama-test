Frequently asked questions

Do I need to install anything, or make an account?

No. Open game.html in a browser — from a static file server, or straight from disk over file:// — and press Start. There's no signup, no download, no dependency to fetch.

Does it need a network connection?

No. The entire simulation — world, traffic, police, missions, physics, audio — runs in one script tag. The only network requests the page ever makes are the ones your browser makes for the page's own files.

Where does my progress get saved?

In this browser's localStorage, under four small keys: best score, lifetime stats, unlocked achievements, and your garage-saved car. See Progression for exactly what each one holds.

Can I lose my save?

Yes — clearing site data, switching browsers, or opening a private/incognito window all leave it behind. There's no account or cloud sync backing it up; it's local storage in the literal sense.

Does it work on my phone?

Yes. Any coarse-pointer device automatically gets on-screen touch pads over the canvas — a D-pad and action buttons — no separate mobile build required. See Controls for the full layout.

What happens when I get busted?

Your wanted level resets to zero and you're placed back at spawn on foot — but your score, lifetime stats and achievements are untouched. It's an endless game; busts are a setback, not a game over.

Is the wanted system too aggressive for a casual run?

Tune it down — police aggression is a pause-menu setting (0.5×/1×/1.5×), or switch on peaceful mode to remove the wanted system entirely. See Controls.

Is the city the same every time I play?

The tile layout is deterministic — same river, same stadium, same block pattern every load, since it's computed from a hash function rather than stored. Traffic, pedestrians, missions and cops are randomized fresh each run.

Is this part of Ollama Chat?

It ships inside the same repository as a bonus project, built by the same person, but it's a fully separate, standalone page with no dependency on the chat app or on Ollama running anywhere. See About for the connection.
